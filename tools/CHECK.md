# Проверка перед отправкой на GitHub

Из корня проекта:

```sh
python3 tools/check.py
```

Нужны Python 3.9+, Git и закреплённые в `foreman.toml` Lune/Rojo, доступные
в PATH. Команда проверяет актуальность CSV локализации, запускает Luau-тесты
и Python-тесты инструментов, собирает place и проверяет пробелы в diff к HEAD
(включая подготовленные к коммиту изменения). При первой ошибке останавливается.
Studio, Roblox Player, облачные проверки и публикация не запускаются.

Для каждого прогона создаётся новая временная папка с `game.rbxlx`, отдельными
логами и `report.json`. Можно указать свою **ещё не существующую** папку:

```sh
python3 tools/check.py --output-dir /tmp/chocolatier-review-1
```

Существующая папка не перезаписывается; папки внутри `src` запрещены, чтобы
результаты проверки не попали в игровой place. Код завершения 0 означает успешную
локальную проверку, ненулевой — ошибку или прерывание. Сбой инструмента и
таймаут 180 секунд на отдельный шаг также попадают в отчёт. Его поля
`studioChecked` и `published` остаются false: сборка не доказывает качество
кадра и не подтверждает выпуск в Roblox.

Отчёт содержит SHA коммита, отпечаток проверяемых исходников и SHA-256 готовой
сборки. Незакоммиченные и новые исходники включаются в отпечаток. Если код,
тесты, инструменты, карта Rojo или локализация изменились за время проверки,
прогон признаётся устаревшим, даже если все команды завершились успешно.
Заметки о работе и временные логи на результат не влияют. SHA коммита сам по
себе не описывает незакоммиченные изменения; для них служит отпечаток.

При устаревшем CSV команда ничего не исправляет сама. Сначала выполните
`lune run tools/export-localization`, проверьте diff и повторите приёмку.
Временные результаты остаются для разбора и удаляются вручную после проверки.
