# Infinite Chocolatier — новая база

## Идея

Инкременталка по мотивам infinite chocolate trick. В начале есть одна
шоколадка. Чтобы получить дольку, игрок проходит короткий жест мышью:

1. проводит по подсвеченным пунктирным линиям;
2. отодвигает нужные куски в целевые места;
3. получает дольку и повторяет цикл.

Позже дольки покупают новые плитки, автонарезатели, автопередвигатели и
умпа-лумпов. Публикация place пока не нужна: разработка идёт локально через
Rojo и Roblox Studio.

## Что сейчас есть

- новый чистый Rojo-проект;
- одна вертикальная плитка 5×5 с высокими прямоугольными дольками;
- один непрерывный диагональный рез и математически обрезанная верхняя область;
- сдвиг верхней диагональной области вправо и немного вверх;
- полноэкранный UI-оверлей в стиле референса: крупная плитка, минимальный
  HUD и инструкция внизу;
- серверный счётчик долек с минимальным троттлингом;
- чистые `Geom` и `Recipe` с тестами через Lune;
- предыдущий MVP был проверен в Roblox Studio; текущая диагональная версия
  собрана локально и ждёт одной аккуратной визуальной проверки;
- локальная сборка лежит рядом с исходниками и не публикуется в Roblox.

## Что сознательно ещё не сделано

- экономика и магазин;
- вторая плитка и автоматизация;
- DataStore, офлайн-доход и звук;
- тонкая настройка жеста и визуальная проверка диагонального сдвига в одном
  экземпляре Roblox Studio;

## Рабочий цикл

```bash
lune run tests/run
rojo build --output /tmp/infinite-chocolatier-check.rbxlx
rojo serve
```

В Studio держим один экземпляр и одну тестовую сессию. Начинать балансировку
имеет смысл после того, как станет удобно пройти диагональный рез и один
сдвиг верхней области реальной мышью.

## Безопасность Roblox Studio

Подробный порядок запуска и закрытия записан в [STUDIO_RUNBOOK.md](STUDIO_RUNBOOK.md).
Критичное ограничение: `sky.get_app_state` может запустить Studio, если путь
не запущен, поэтому после Quit состояние проверяется только через список
приложений. Для работы используется единственный канонический путь
`/Applications/RobloxStudio.app`; путь `UnzippedBundle` не используется.
