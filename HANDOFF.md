# Infinite Chocolatier — новая база

## Идея

Инкременталка по мотивам infinite chocolate trick. В начале есть одна
шоколадка. Чтобы получить дольку, игрок проходит короткий жест мышью:

1. последовательно проводит четыре подсвеченных разреза;
2. переставляет две крупные части;
3. вставляет двухдольный блок в верхнюю нишу;
4. получает оставшуюся исходную дольку и повторяет цикл.

Позже дольки покупают новые плитки, автонарезатели, автопередвигатели и
умпа-лумпов. Публикация place пока не нужна: разработка идёт локально через
Rojo и Roblox Studio.

## Что сейчас есть

- одна вертикальная плитка 5×5 с высокими прямоугольными дольками и рельефом;
- четыре обязательных разреза: главная диагональ и три коротких разреза по
  бороздкам, которые действительно отделяют все пять частей;
- готовность разреза наступает только у физического конца линии, а переход к
  следующему разрезу — только после отпускания мыши или пальца;
- пять исходных частей: нижняя область, две крупные верхние области,
  двухдольный блок и одиночная долька;
- диагональ `(0, 3.5) -> (5, 1.5)` и перестановка крупных частей на `(2, -1)`
  и `(-3, +1)` воспроизводят Curry-схему видео;
- площадь внешней дольки распределяется полосой `5 × 0.2 = 1` вдоль нового
  диагонального шва;
- сама полоса игроку не показывается: нижние края спрайтов двух верхних
  полигонов оптически продолжаются на `0,2` ряда вместе с рамками и рельефом,
  поэтому после сборки остаётся только тонкий естественный шов;
- продолжение готово до начала разреза в отдельной подложке ниже физических
  частей: оно не перекрывает фаски исходных долек, а при сдвиге едет вместе с
  верхними частями без полупрозрачного слоя, дорисовывания или изменения формы;
- двухдольный блок закрывает верхнюю нишу, а подсвеченная одиночная долька —
  настоящий исходный кусок, не новый шоколадный `Instance`;
- полноэкранный UI с минимальным HUD и инструкцией внизу;
- стандартный Roblox-персонаж не создаётся: игра пока целиком живёт в UI,
  поэтому за экраном нет падений в пустоту и циклических респавнов;
- серверный счётчик долек с минимальным троттлингом;
- чистые `Geom` и `Recipe` с тестами через Lune;
- покадровый разбор 127 кадров записан в
  [REFERENCE_ANALYSIS.md](REFERENCE_ANALYSIS.md);
- новая пятичастная версия прошла полный визуальный цикл в Studio; итоговый
  кадр сохранён в
  [infinite-chocolatier-preloaded-stretch-result.png](infinite-chocolatier-preloaded-stretch-result.png).

## Почему используется аналитический UI-клиппинг

Roblox UI не даёт надёжной произвольной polygon mask, а `EditableImage` и
динамические mesh API добавили бы зависимости и риски совместимости. Поэтому
обычные целые дольки остаются единичными `Frame`, а только примитивы,
пересечённые диагональю, растрируются вертикальными колонками шириной один
пиксель. Прямоугольные границы обрезаются через `ClipsDescendants`. Колонки
создаются один раз при layout; во время жестов двигаются пять готовых
родительских групп. Это даёт гладкий край без постоянной перерисовки.

## Рабочий цикл

```bash
lune run tests/run
rojo build --output /tmp/infinite-chocolatier-sol-check.rbxlx
rojo serve
```

На 2026-08-21: новая Curry-геометрия даёт `30 прошло, 0 упало`, Rojo build
успешен. В одном экземпляре Studio вручную проверены цельная плитка,
последовательность всех четырёх разрезов с сохранением готовых швов, разлёт
только после последнего разреза, захват крупной диагональной области,
вставка двухдольного блока, внешняя исходная долька, серверное начисление
ровно одной дольки и автоматический сброс. Отдельно проверено, что широкая
Curry-полоса больше не видна, сетка продолжается через неё без ступенек, а
заранее подготовленная кромка не возникает на глазах во время сдвига.
На контрольном стартовом кадре 2026-08-22 все 25 долек, включая пересечённые
диагональю, имеют одинаковые фаски и внутренний рельеф: Curry-кромка вынесена
в отдельную нижнюю подложку и не перекрывает цельный шоколад.
Отдельно проверено, что отпускание на прежних 94% не завершает диагональ, а
следующий пунктир появляется лишь после доведения последних пикселей и
отпускания. Developer Console показала `0` ошибок и `0` предупреждений.

`Agent Long Run ON` не смог подтвердить удержание сна, поэтому тест был
коротким и непрерывно контролируемым. После проверки выполнен штатный OFF,
лишние удержания сняты, Studio закрыта и через список приложений подтверждено,
что активных экземпляров нет.

## Безопасность Roblox Studio

Подробный порядок запуска и закрытия записан в [STUDIO_RUNBOOK.md](STUDIO_RUNBOOK.md).
Критичное ограничение: `sky.get_app_state` может запустить Studio, если путь
не запущен, поэтому после Quit состояние проверяется только через список
приложений. Для работы используется единственный канонический путь
`/Applications/RobloxStudio.app`; путь `UnzippedBundle` не используется.
